ОЦЕНКА КАЧЕСТВА ЗУБЧАТЫХ ПЕРЕДАЧ ОАО "ГАЗ"

В.А.Смирнов

    Выявление различных дефектов зубчатых передач базируется на анализе вибрационных сигналов, измеренных на корпусе устройства, в состав которого входит зубчатая передача.
    Предлагаемые фирмой "ИНКОТЕС" методы используют новейшие достижения в области обработки и анализа вибрационных сигналов, что позволяет выявлять практически любой дефект зубчатых передач.
Применение предлагаемых методов диагностики позволяет контролировать качество зубчатых передач и выявлять их дефекты на стадиях проектирования, изготовления, доводки и испытаний

1. Описание объекта

    Для создания методики и программного обеспечения по диагностике дефектов зубчатых передач, специалистами фирмы "ИНКОТЕС" (г.Н.Новгород) совместно со специалистами ОАО "ГАЗ" проведены исследования вибрационных характеристик зубчатых передач автомобилей с помощью портативной вибродиагностической системы ДСА-2001 и соответствующего программного обеспечения.
    В рамках исследований были проведены 2 вида испытаний :
- испытания задних мостов автомобиля ГАЗ-3102 на испытательном стенде ОАО "ГАЗ" для исследования вибрационных характеристик главной зубчатой передачи редуктора;
- испытания конических зубчатых пар автомобиля ГАЗ-31029 на контрольно- обкатном станке участка доводки зубчатых пар в процессе их притирки и приемки ОТК.
    При 1-м виде испытаний исследовались два задних моста:
- 1-й мост с обычной зубчатой передачей;
- 2-й мост с зубчатой передачей, имеющей улучшенное (оптимизированное) пятно контакта.
    При 2-м виде испытаний исследовалось 11 зубчатых пар с различным качеством изготовления и степенью притертости, при этом сравнивались результаты субъективной оценки качества пар мастерами ОТК ("слухачами") и оценки, полученной на основе исследования спектров вибрации с помощью ДСА-2001.

2. Методика диагностирования

    Диагностика дефектов зубчатых передач базируется на анализе:
- синхронно накопленных сигналов виброскорости и виброускорения, измеренных на корпусе объекта;
- усредненных спектров виброускорения в диапазоне до 16 кГц при частотном разрешении 0,8 Гц;
- огибающей сигналов в полосе частот
проявления зубцовых гармоник и в широкой полосе частот;
- спектров огибающей в полосе до 2 кГц;
- кепстров.
    Применение указанных характеристик позволяет не только выявлять наличие дефектов и аномалий зубчатых передач, но и оценивать степень их опасности, что особенно необходимо при отбраковке шестерен.

3. Испытания зубчатых пар на испытательном стенде УКЭР в составе заднего моста автомобиля ГАЗ-3102

    В процессе испытаний проводились оценка влияния параметров пятна контакта на качество и вибрационные характеристики зубчатых передач заднего моста автомобиля ГАЗ-3102, а также определялась возможность создания вибрационного критерия оценки этого влияния.
    В качестве основной ведущей пары для данного типа заднего моста используется понижающая коническая пара шестерен со следующими параметрами:
- число зубьев ведущей шестерни - 8;
- число зубьев ведомой шестерни - 41;
- передаточное отношение- 5,125.
    Вибрация измерялась на корпусе редуктора заднего моста при его работе на переднем и заднем ходу без нагрузки и с нагрузкой 1 кг/см2, создаваемой с помощью рычага, на частотах вращения ведущего вала 1500, 3000, 4000 об/мин (25, 50, 67 Гц).
    Испытывались два моста - с обычным и улучшенным (оптимизированным) пятном контакта основной ведущей пары.

4. Испытания зубчатых пар задних мостов автомобиля ГАЗ-31029 на контрольно-обкатном станке

    Параметры исследуемых гипоидных шестерен заднего моста:
- ведущая шестерня - 10 зубьев;
- ведомая шестерня - 39 зубьев;
- передаточное отношение - 3,9.
    Испытания проводились на контрольно- обкатном станке Глиссон-512.
    Испытания проводились в два этапа - на первом этапе вибрационные параметры измерялись для непритертых пар, на втором- для притертых пар, предъявляемых мастерам ОТК ("слухачам") для оценки шумовых характеристик.
    Было испытано 11 пар, сводные данные по которым приведены в табл.2. В этой же таблице приведены значения диагностических параметров, которые использовались для оценки состояния зубчатых пар. Параметры получены по синхронно накопленным спектрам виброускорения с использованием зубцовых кратностей ведущего вала.
    Сравнивая два этих параметра, следует признать, что К3 более объективно отражает изменение состояние зубчатых пар, чем К2. Зависимость К3 от состояния зубчатых пар приведена на рис. 3.
    Из рассмотрения рис.3 следует, что хорошие пары имеют значение К3, не превышающее 1,0 , пары, определенные ОТК, как имеющие "приматывание" (низкочастотную амплитудную модуляцию)- не более 2,5, для отбракованной пары это значение около 3 и более- эти значения параметра К3 можно использовать для оценки качества и отбраковки пар и применять при контроле ОТК.
    В процессе испытаний были получены также количественные критерии оценки качества притертости, которое, судя по тому как это осуществляется в настоящее время, оценивается по субъективным критериям .
    В качестве оценочного параметра качества притертости пар можно использовать критерий, рассчитанный по усредненному спектру виброускорения с использованием псевдовекторного подхода. Критерий (Аz) представляется как разность векторов, полученных по 2-й и 1-й зубчатым гармоникам, измеренным в вертикальном и осевом направлениях (см. рис.4).
    Как следует из рассмотрения рис.5, значения Аz для притертых пар не превышает 0,5 - это значение можно использовать для оценки качества притертости при обкатке на станке.

5. Программа диагностики зубчатых пар

    1. Проведенные исследования показали, что для предъявленных дефектов, связанных с изготовлением зубчатых передач, получены устойчивые диагностические признаки для их отбраковки.
    2. На основании полученных результатов разработана 1-я версия программного обеспечения для отбраковки зубчатых пар в условиях производства.
    Программа рассчитана для применения персоналом без специальной квалификации.
    Программа позволяет с определенной вероятностью выявлять дефекты и неисправности зубчатых передач, определяемые:
- погрешностями изготовления (неравномерностью шагов, радиальным биением бочкообразностью зубьев и др.);
- некачественной обработкой (шероховатостью боковых поверхностей зубьев, питтингом, микротрещинами, забоинами);
- некачественной сборкой (несоосностью валов, боковыми зазорами.
    3. Отработка программного обеспечения осуществлялась совместно со специалистами ОАО"ГАЗ".
