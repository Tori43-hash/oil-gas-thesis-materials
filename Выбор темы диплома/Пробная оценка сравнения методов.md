# Предварительная проверка смысла сравнения двух зависимостей

Использованы 49 строк исследований 1998 года по скважинам 6080–6086. Это предварительная численная проверка, не заключение о достаточности темы для ВКР.

Сопоставлены:

- двучленная зависимость `D = A·Q + B·Q²`, где `D = Pпл² − Pзаб²`; подбор в координатах `D/Q — Q`;
- степенная зависимость `Q = C·Dⁿ`; подбор в логарифмических координатах.

Подборы минимизируют разные ошибки. Для окончательного сравнения это нужно отдельно учитывать; универсальное преимущество формулы по данному пробному расчёту не установлено.

При подборе на всех точках максимальное расхождение расчётных дебитов двух моделей в измеренных точках — около 1,43% измеренного дебита.

Для проверки восстановления замеров поочерёдно исключалась целая группа с одним диаметром шайбы, включая повторные замеры на нём. Коэффициенты определялись по оставшимся строкам той же скважины; затем рассчитывались исключённые значения. Средняя абсолютная относительная ошибка по всем 49 проверкам:

| Зависимость | Средняя ошибка | Максимальная ошибка |
|---|---:|---:|
| Двучленная | 2,85% | 9,53% |
| Степенная | 2,87% | 9,11% |

Это проверка внутри архивных исследований. Замеры не являются независимыми данными будущей эксплуатации. Погрешности приборов и достоверность первичных значений неизвестны; статистически и практически значимое преимущество одной зависимости не доказано. Некоторые исключения проверяют края исходного диапазона, а не только интерполяцию.

Вывод для выбора темы: сравнение двух формул имеет понятный инженерный смысл, но в этом наборе предварительный расчёт даёт близкие результаты. Сильную актуальность диплома нельзя обосновывать утверждением, что выбор формулы здесь резко меняет расчёт дебита. Как расчётная глава более широкой работы такое сопоставление возможно; достаточность отдельного диплома пока не обоснована.
