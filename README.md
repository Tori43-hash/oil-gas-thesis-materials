# Материалы для диплома по нефтегазовому делу

Приватная копия локальной коллекции для выбора и подготовки дипломной работы по разработке и эксплуатации нефтяных и газовых месторождений.

Снимок подготовлен 1 ноября 2026 года. Сохранены 7 401 уникальный файл общей длиной 2 961 350 513 байт, около 2,76 ГиБ. Исходная локальная коллекция не изменялась.

## Состав

- Каталоги `01`–`27` и `08 ХАЛЯВА`: архивные документы, дипломные тексты, таблицы, книги, чертежи и вспомогательные материалы.
- [Выбор темы диплома](<Выбор темы диплома/>): проверка источников, исходные строки исследований скважин, пробные расчёты и воспроизводимые проверки.
- [Поиск по КубГТУ](<exa-results/kubstu-vkr-2026-11-01/Обзор.md>): обзор открытых источников и найденные документы.
- `_загрузка_диплома`: журналы, сведения об источниках и код первоначальной загрузки; незавершённые `.part` исключены.

Материалы преимущественно исторические. Названия папок и чужие дипломные тексты сами по себе не подтверждают происхождение и достоверность исходных данных.

## Удаление повторов только из публикуемой копии

- 1 082 архива исключены после проверки размеров и CRC файлов в распакованных каталогах. Имена некоторых старых записей имели проблемы с кодировкой; в таких случаях проверялось наличие содержимого по размеру и CRC внутри соответствующего распакованного каталога.
- 2 447 точных повторов исключены по SHA-256. Разные редакции и просто похожие документы сохранены.
- 1 366 файлов `.part` и два пустых архива исключены.
- Единственный оставленный RAR — `Блок-диагр.part2.rar`: распакованного содержимого не найдено. Это фрагмент многотомного архива; наличие этого тома не гарантирует возможность его распаковки.

Полная привязка первоначальных путей к сохранённым копиям: [_export/files.csv](<_export/files.csv>). Результаты проверки архивов: [_export/archives.csv](<_export/archives.csv>).

Часть ссылок в ранее созданных аналитических заметках содержит абсолютные пути первоначального компьютера. Для поиска соответствующего файла используйте его относительный путь и реестр `_export/files.csv`; повтор мог быть сохранён в другом каталоге.

## Большие файлы

Два файла размером более 50 МиБ хранятся через Git LFS. Остальные файлы — обычные Git-объекты.

Для получения полной копии нужен Git LFS:

```sh
git lfs install
git clone https://github.com/Tori43-hash/oil-gas-thesis-materials.git
```

Авторство исходных материалов не приписывается владельцу репозитория. Эта коллекция не является готовой самостоятельной выпускной работой.
